# Provider research notes

- **DEX Screener official API reference:** https://docs.dexscreener.com/api/reference. The reference documents `GET /token-pairs/v1/{chainId}/{tokenAddress}` and `GET /tokens/v1/{chainId}/{tokenAddresses}`; the latter supports up to 30 comma-separated token addresses. Pair payloads include chain/dex IDs, pair URL, base/quote token, USD price, transaction counts, volume, price change, liquidity, FDV, market cap, pair creation time, and optional token info. The reference lists 300 requests/minute for pair/token endpoints and 60 requests/minute for latest token profiles. This project uses the documented batched `tokens/v1` endpoint and a short server-memory cache.
- **GoPlus EVM Token Security API:** https://docs.gopluslabs.io/reference/tokensecurityusingget_1. The official page shows `GET https://api.gopluslabs.io/api/v1/token_security/{chain_id}`. The provider docs require a chain ID and contract address query parameter; chain support must be checked per function. The adapter only maps fields actually returned and treats absent required fields as UNKNOWN. `GOPLUS_ACCESS_TOKEN` is optional and server-only; the public docs page did not expose full rate-limit details in extracted content, so deployments should observe provider responses and configure conservative request volume.
- **GoPlus Solana Token Security API (Beta):** https://docs.gopluslabs.io/reference/solanatokensecurityusingget. The official reference confirms `https://api.gopluslabs.io/api/v1/solana/token_security`, but its extracted page did not disclose query parameters or response schema. No undocumented Solana GoPlus call is made. Solana currently uses direct JSON-RPC mint parsing and remains outside the main feed while owner-aggregated holder concentration and Token-2022 extension checks are incomplete.
- **RugCheck API:** https://api.rugcheck.xyz/swagger/index.html and https://api.rugcheck.xyz/swagger/doc.json. The official OpenAPI describes token scoring/report APIs; the bulk report and bulk summary endpoints explicitly require API-key authentication, with 401/429 responses. No RugCheck request is used until a route and credential scope appropriate to the deployment are verified.
- **Agent-Reach reference:** https://github.com/Panniantong/Agent-Reach. The project context records a prior audit: Agent-Reach is a CLI/router/diagnostic tool, not a browser integration; its invocation and supported auth must be configured in a separate worker rather than guessed inside a Netlify Function. This repository therefore does not invent CLI flags and accepts only normalized JSON from an external adapter.
